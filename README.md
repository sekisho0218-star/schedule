# 週間バーチカル手帳

> **Android アプリ版**は [`android/`](android/README.md) にあります（ホーム画面ウィジェット対応）。以下は PC・スマホのブラウザで使える Web アプリ（PWA）版の説明です。

PC とスマホの両方で使えるスケジュール管理アプリ（PWA）です。ジブン手帳の週間バーチカルを参考にしたレイアウトで、Googleカレンダーと同期できます。

## 機能

- **週間バーチカル**（メイン画面）
  - 月曜始まり、8:00〜24:00 の時間軸
  - 曜日ごとの色分け：平日＝黄、土曜＝青、日曜＝赤
  - 時間軸の空いている場所をタップ/クリック → その時刻で予定を追加
  - 日付をタップ → 終日予定を追加、予定をタップ → 編集・削除
  - 重なっている予定は横に並べて表示、今日の現在時刻にラインを表示
- **タスクリスト**（各日の下に5件）
  - 「＋」の欄に入力して Enter で追加
  - チェックを入れると自動で消えます
- **月間ページ**：上部の「週間 / 月間」で切り替え。日付をタップするとその週の週間表示へ移動
- **Googleカレンダー同期**：表示中の月の予定を取得。連携中に追加・編集・削除した予定は Google 側にも反映
- **ウィジェット表示**：`index.html?widget=1` で操作ボタンを省いたコンパクトな週間バーチカルを表示（5分ごとに自動同期）
- 操作：← → キー、スマホは左右スワイプで前後の週/月へ移動
- オフラインでも表示可能（Service Worker でキャッシュ）

※ タスクと「Google未連携時に作成した予定」は、その端末（ブラウザ）内に保存されます。

## 使い方

ビルド不要の静的サイトです。HTTPS で配信すればそのまま動きます。

### GitHub Pages で公開する（おすすめ）

1. GitHub のリポジトリで **Settings → Pages** を開く
2. Source を「Deploy from a branch」、ブランチを選んで `/ (root)` を指定して保存
3. 数分後に `https://<ユーザー名>.github.io/schedule/` で開けます

### ローカルで試す

```bash
python3 -m http.server 8080
# → http://localhost:8080 を開く
```

## Googleカレンダーとの連携設定

1. [Google Cloud Console](https://console.cloud.google.com/) でプロジェクトを作成
2. 「API とサービス → ライブラリ」で **Google Calendar API** を有効化
3. 「OAuth 同意画面」を設定（ユーザーの種類：外部。テストユーザーに自分の Google アカウントを追加）
4. 「認証情報 → 認証情報を作成 → OAuth クライアント ID」
   - アプリケーションの種類：**ウェブ アプリケーション**
   - 承認済みの JavaScript 生成元：アプリの URL のオリジン
     （例：`https://<ユーザー名>.github.io`、ローカルなら `http://localhost:8080`）
5. 発行された「クライアント ID」をアプリの ⚙（設定）に貼り付けて「保存して連携」
6. Google のログイン画面で許可すると同期されます。以降は「⟳ 同期」ボタンで再同期

カレンダーID を空欄にするとメインのカレンダー（primary）を使います。

## アプリとしてインストール

- **PC（Chrome / Edge）**：アドレスバー右側のインストールアイコン → インストール
- **Android（Chrome）**：メニュー → 「ホーム画面に追加」／「アプリをインストール」
- **iPhone（Safari）**：共有ボタン → 「ホーム画面に追加」

インストール後、アプリアイコンを長押しすると「週間ウィジェット表示」「月間」のショートカットが使えます（対応端末のみ）。

## ウィジェットについて

Web アプリ（PWA）は、iOS / Android のホーム画面に置く**ネイティブのウィジェット**を作ることができません。現時点では次の方法で代用します。

- `index.html?widget=1` をホーム画面に追加して、ウィジェット風の週間表示を1タップで開く
- PC ではウィジェット表示を小さなウィンドウで開いて常駐させる

本物のホーム画面ウィジェットが必要な場合は、Android（Jetpack Glance）や iOS（WidgetKit）のネイティブ実装を別途追加する必要があります。

## ファイル構成

```
index.html            画面の骨組み・ダイアログ
styles.css            デザイン（曜日色・バーチカル・スマホ対応）
js/app.js             週間/月間の描画、タスク、ダイアログ、同期処理
js/dates.js           日付ユーティリティ（月曜始まり）
js/store.js           端末内保存（予定・タスク・設定）
js/gcal.js            Googleカレンダー API 連携
sw.js                 オフライン用 Service Worker
manifest.webmanifest  PWA 設定
icons/                アプリアイコン
```
