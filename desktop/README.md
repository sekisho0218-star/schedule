# バーチカル手帳（Windows デスクトップ版）

PC のデスクトップに、今週の週間バーチカル（8:00〜24:00）と各日のタスク5件を表示するアプリです。
予定は Google カレンダー、タスクは Google ToDo リストと同期するので、Android 版と同じ内容が表示されます。

## できること

- **週間バーチカル / 月間** の切り替え（月曜始まり、平日＝黄・土＝青・日＝赤）
- 予定の追加・編集・削除（時間軸の空いた所をクリックで追加）
- タスク：各日3件。「＋」に入力して Enter で追加、チェックで完了（消える）
- 「15:00 教材発注」「15:00-16:30 面談準備」のように**先頭に時刻を付けたタスクはスケジュールに表示**（タスクリストには出ません）
- **表示モード**（ツールバーのボタン、またはタスクトレイのメニューで切り替え）
  - 🖥 **デスクトップに貼り付け**：他のウィンドウの後ろに表示。「デスクトップを表示」しても消えません
  - 📌 **常に手前に表示**：他のウィンドウより常に前に表示
- 🔒 位置とサイズを固定、透明度（40〜100%）、Windows 起動時に自動で開く
- 5分ごと、およびウィンドウをクリックしたときに自動同期
- ウィンドウの幅に合わせて文字が大きくなります

ウィンドウはツールバーの何もない所をドラッグして移動、端をドラッグしてサイズ変更できます。
「－」で隠したときは、タスクトレイ（画面右下）のアイコンをクリックすると再表示されます。

## シフト表との連携

塾のシフト表（Google スプレッドシートの「シフト表(NEW)」タブ）から、自分の列のコマを読み取って Google カレンダーに反映します。

1. ⚙ 設定 →「シフト表との連携」で、シフト表の URL・講師名（例：赤松）・反映先のカレンダー（授業の予定が入っているカレンダー）を入れ、「シフト表の予定を Google カレンダーに反映する」をオン
2. 「今すぐ照合」を押す（以後は30分ごとに自動で照合）

| 種類 | 扱い |
|---|---|
| **授業**（「中2木堂(数)/小5堀谷(算)」「中1数学」「指定校コース」など） | シフト表に合わせて**自動で追加・変更・削除**（初回だけは一覧を確認してから） |
| **授業以外**（「11:00 中3竹内様」、日曜の「テスト対策」など） | 「授業以外は反映しますか？」と確認してから追加 |
| **シフト表にない予定**（反映先カレンダーの、授業以外の予定） | 「削除しますか？」と確認（初期値は削除しない） |

- 「反映しない」を選んだ項目は次回から聞きません（設定の「『反映しない』をリセット」で元に戻せます）
- 照合するのは今日以降の予定だけです
- 予定の時刻は手帳の書き方に合わせます：開始は 16:05→16:00 のように丸め、小学生だけのコマは60分（平日16:05の枠は16:30〜）、それ以外は90分。「数学(16:05～)」「中2(15:10)」のように時刻が書いてあればその時刻から
- 学年が書かれていない生徒は「名簿」タブの学年を使います
- シフト表は「リンクを知っている全員が閲覧可」になっている必要があります（ログインは不要）
- 照合は Windows 版のアプリが起動しているときに行われます。反映した予定は Google カレンダー経由で Android 版にも表示されます

## Google の設定（初回のみ・PC と Android 共通）

予定とタスクを読み書きするため、Google Cloud に「このアプリ用の鍵」を作ります。無料です。

### 1. プロジェクトと API

1. https://console.cloud.google.com/ を開き、上部のプロジェクト選択 → **新しいプロジェクト**（名前は例：`vertical-techo`）
2. 左メニュー **API とサービス → ライブラリ** で次の2つを検索して **有効にする**
   - **Google Calendar API**
   - **Google Tasks API**

### 2. OAuth 同意画面（Google Auth Platform）

1. **API とサービス → OAuth 同意画面**（「Google Auth Platform」と表示される場合もあります）→ **開始**
2. アプリ名：`バーチカル手帳`、サポートメール：自分のアドレス → 対象：**外部** → 連絡先：自分のアドレス → 作成
3. **対象（Audience）** の画面で、公開ステータスは **「テスト中」のまま** にし、**テストユーザー** の「＋ Add users」で自分の Gmail を追加する
   - 「テスト中」では Google の決まりで、Windows 版のログインが **7日ごとに切れます**。切れると **自動でブラウザに Google のログイン画面が開く** ので、アカウントを選んで「続行」を押してください（Android 版は再ログイン不要です）
   - ログイン時に「Google はこのアプリを確認していません」と出たら **続行** を選びます
   - 本番環境に公開するとログインし直しは不要になりますが、ホームページとプライバシーポリシーの URL が必要です（リポジトリを公開して GitHub Pages を使えば `privacy.html` を利用できます）

### 3. Windows 版の OAuth クライアント

1. **API とサービス → 認証情報 → 認証情報を作成 → OAuth クライアント ID**
2. アプリケーションの種類：**デスクトップ アプリ**、名前：`Windows`
3. 表示された **クライアント ID** と **クライアント シークレット** を、アプリの ⚙ 設定に入力して「保存してGoogleにログイン」

### 4. Android 版の OAuth クライアント（タスク同期用）

1. 同じく **認証情報を作成 → OAuth クライアント ID**
2. アプリケーションの種類：**Android**
3. 次の値を入力して作成（アプリに入力するものはありません）

| 項目 | 値 |
|---|---|
| パッケージ名 | `jp.sekisho.vertical` |
| SHA-1 証明書フィンガープリント | `6F:5C:DA:7B:8E:94:94:20:60:B9:C5:BB:14:9C:E2:E2:C4:DF:39:24` |

4. Android アプリの ⚙ 設定 → **Google ToDo リストと同期** を押し、アカウントを選んで許可
   （端末にあったタスクは Google ToDo リストに移動します）

### タスクの扱い

- Google ToDo リストの「**マイタスク**」のうち、**期限が設定されたもの**がその日のタスクとして表示されます
- **時刻のないタスク** → 各日のタスクリスト（最大3件）
- **名前の先頭に時刻を書いたタスク** → スケジュール（時間軸）に「☐」付きの灰色の枠で表示
  - `15:00 教材発注` → 15:00〜15:30、`15:00-16:30 面談準備` → 15:00〜16:30（全角数字でも可）
- **Google ToDo リストで日時を設定したタスク** → Google カレンダーに時刻付きで表示されるので、**同じ日に同じ名前の時刻付きの予定があるタスク**はスケジュールにだけ表示（「☐」付き。クリックで完了）し、タスクリストには出しません
  - Google Tasks API はタスクの時刻を読めない（期限は日付のみ）ため、このように名前で対応づけています
- チェック（またはスケジュール上のタスクをクリック →「完了」）すると Google 側では「完了」になります

## 開発者向け

```bash
cd desktop
npm install
npm start          # 起動
npm run dist       # Windows インストーラーを作成（dist/）
```

`main.js`（ウィンドウ・タスクトレイ・表示モード）、`google.js`（Google ログインと API）、`config.js`（設定の保存。トークンは Windows の暗号化機能で保護）、`renderer/`（画面）。
GitHub Actions（`.github/workflows/windows.yml`）が `desktop/` の変更ごとにインストーラーを作り、Releases の `latest-windows` に置きます。
