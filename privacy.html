バーチカル手帳 プライバシーポリシー

最終更新日：2026年11月3日

「バーチカル手帳」（以下「本アプリ」。Android 版・Windows 版・Web 版を含みます）は、個人が自分の予定とタスクを管理するために作成したアプリです。本アプリにおける情報の取り扱いは次のとおりです。

1. 取得する情報

本アプリは、利用者が Google アカウントでのログインを許可した場合に限り、Google API を通じて次の情報にアクセスします。

  • Google カレンダーのカレンダー一覧と予定（閲覧・追加・変更・削除）
  • Google ToDo リスト（Google Tasks）のタスク（閲覧・追加・変更・完了）

2. 利用目的

取得した情報は、本アプリの画面（週間バーチカル・月間表示・ウィジェット）に予定とタスクを表示し、利用者の操作に応じて予定やタスクを追加・変更するためだけに使用します。

3. 保存と第三者提供

  • 予定とタスクのデータは、利用者の端末（PC・スマートフォン）内と利用者自身の Google アカウントにのみ保存されます。
  • 本アプリの開発者が運営するサーバーはなく、開発者が利用者のデータを収集・閲覧・保存することはありません。
  • 取得した情報を第三者に提供・販売することはありません。広告や分析の目的には使用しません。
  • ログイン情報（認証トークン）は、各端末の OS が提供する保護された領域に保存されます。

4. Google API サービスのユーザーデータに関するポリシー

本アプリによる Google API から取得した情報の使用および他のアプリへの転送は、Google API サービスのユーザーデータに関するポリシー（限定的使用の要件を含む）に準拠します。

5. アクセス権の取り消し

本アプリの設定画面からログアウトするか、Google アカウントのサードパーティ アクセス設定から本アプリのアクセス権をいつでも取り消せます。

6. お問い合わせ

本ポリシーに関するお問い合わせは、Google Cloud の OAuth 同意画面に記載したデベロッパーの連絡先メールアドレスまでご連絡ください。
