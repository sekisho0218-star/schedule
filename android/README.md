# バーチカル手帳（Android アプリ）

ジブン手帳の週間バーチカルを参考にした Android 用スケジュール帳です。Googleカレンダーと同期でき、ホーム画面ウィジェットで今週の予定とタスクを確認できます。

## 機能

| 機能 | 内容 |
|---|---|
| 週間バーチカル | 月曜始まり、8:00〜24:00。平日＝黄、土曜＝青、日曜＝赤で色分け。現在時刻のラインを表示 |
| 予定の追加・編集 | 時間軸の空いた所をタップ → その時刻で追加。日付をタップ → 終日予定を追加。予定をタップ → 編集・削除 |
| タスク | 各日の下に3件（時刻のないタスク）。「15:00 〇〇」のように先頭に時刻を付けたタスクはスケジュールに表示。「＋」に入力して追加、チェックを入れると自動で消える。文字をタップで編集。Google ToDo リストと同期すれば PC 版と共有 |
| 月間表示 | 上部の「週間／月間」で切り替え。日付をタップするとその週へ移動 |
| Googleカレンダー同期 | 端末に登録した Google アカウントのカレンダーを読み書き。「⟳」で今すぐ同期 |
| ウィジェット | 今週の週間バーチカル＋各日のタスク5件。ウィジェット上でタスクのチェックも可能 |
| 操作 | 左右スワイプで前後の週／月へ移動 |

### シフト表との連携（自動照合）

⚙ 設定 →「シフト表との連携」で、シフト表の URL・講師名・反映先のカレンダーを入れてオンにすると、**30分ごとに**シフト表（「シフト表(NEW)」タブ）と照合します。

- **授業**：自動で追加・変更・削除（初回だけは一覧を確認してから）。繰り返し予定はその回だけを変更します
- **授業以外**（「中3竹内様」など）と**シフト表にない予定**：通知でお知らせ → タップすると「授業以外は反映しますか？」の画面
- 「反映しない」を選んだ項目は次回から聞きません
- 二重になったときは ⚙ →「シフト表から追加した予定を一括削除」で、照合で**追加した**予定だけをまとめて削除できます（同じ時間に同じ授業があるものには「重複」と表示。元からあった予定を書き換えたものは対象外）。削除後の次の照合は、もう一度確認画面から始まります
- 自動照合はスマホで行います（Windows 版は「今すぐ照合」のみ。両方で自動にすると二重登録のおそれがあるため）
- 読み取りのルールは Windows 版と同じです（[詳細](../desktop/README.md#シフト表との連携)）

### Googleカレンダーとの同期のしくみ

Android の「カレンダープロバイダ」を使います。端末の **設定 → パスワードとアカウント（アカウント）** に Google アカウントが登録され、カレンダーの同期がオンになっていれば、OS が自動で Google と同期します。アプリで追加・編集した予定は Google カレンダーにも反映されます。Google Cloud の設定や API キーは不要です。

- 予定の保存先カレンダーは ⚙（設定）で選べます。
- 繰り返し予定は表示のみ対応です。編集はダイアログの「カレンダーアプリで開く」から行ってください。
- タスクは、⚙ 設定の「Google ToDo リストと同期」をオンにすると Google ToDo リストに保存され、PC 版と共有されます（オフのときは端末内のみ）。事前に Google Cloud の設定が必要です → [設定手順](../desktop/README.md#google-の設定初回のみpc-と-android-共通)

## インストール方法

### GitHub Actions でビルドされた APK を使う（PC 不要）

1. GitHub のリポジトリページ → **Actions** → 「Android APK」→ 最新の成功した実行を開く
2. 下部の **Artifacts** から `vertical-techo-apk` をダウンロードして展開（`app-debug.apk`）
3. APK をスマホに送り、開いてインストール（「提供元不明のアプリ」の許可が必要）
4. 初回起動時にカレンダーへのアクセスを「許可」

APK はリポジトリ内の固定鍵（`app/debug.keystore`）で署名しているので、新しいビルドをそのまま上書きインストールできます（タスクも保持されます）。

### Android Studio でビルドする

`android/` フォルダを Android Studio で開き、実行ボタンを押します。

## ウィジェットの追加

ホーム画面の空いている所を長押し → ウィジェット → 「バーチカル手帳」の「週間バーチカル」を配置。4×4 以上の大きさがおすすめです（サイズ変更可）。

- 予定部分をタップ → アプリを開く
- □ をタップ → そのタスクを完了（消える）
- ⟳ → Google との同期を依頼して再表示
- 「⇄ 今日から」→ 今日を一番左にした7日間に切り替え（「⇄ 月曜から」で月曜始まりに戻す。ウィジェットごとに設定）
- 予定の変更は自動で反映され、30分ごとにも更新されます

## 構成

```
app/src/main/java/jp/sekisho/vertical/
  MainActivity.kt              起動画面
  data/
    CalendarRepository.kt      端末カレンダー（＝Googleカレンダー）の読み書き・同期依頼
    TaskRepository.kt          タスク（1日5件・完了で削除）
    Dates.kt                   月曜始まりの日付計算、重なる予定の列割り当て
    Models.kt / Prefs.kt / DataSignals.kt
  ui/
    MainScreen.kt              ツールバー・画面切り替え・権限
    WeekScreen.kt              週間バーチカル＋タスク
    MonthScreen.kt             月間
    Dialogs.kt                 予定・タスク・設定のダイアログ
    MainViewModel.kt / Palette.kt / Common.kt
  widget/
    WeekWidget.kt              ホーム画面ウィジェット（Glance）
    WeekBitmapRenderer.kt      ウィジェットのバーチカル部分を描画
    WidgetActions.kt           タスク完了・同期ボタン
    WidgetUpdater.kt           定期更新・カレンダー変更の監視
```

動作環境：Android 8.0（API 26）以上
