# 今日のシフト（Android）

塾のシフト表（Google スプレッドシート「シフト表(NEW)」タブ）から、**1日分の全員のシフト**を表示するアプリです。バーチカル手帳とは別のアプリです。

- シフト表と同じ並び：横に講師名、縦に時間帯。各マスに学年・生徒名・科目（シフト表の書き方のまま）
- 画面の幅に全員が入るよう、広い画面では横一列、狭い画面では講師を2段に分けて表示（横スクロールなし）。誰も入っていない時間帯は省略
- 「〇〇様」などの授業以外の書き込みも表示
- 自分の列（⚙ で名前を設定）と、今の時間帯を色付け
- ‹ › でほかの日、「今日」で今日に戻る。⟳ で読み込み直し（開いたときも10分以上たっていれば自動で読み込み）
- 前回読み込んだ内容は端末に保存するので、電波がないときも表示できます
- 学年が書かれていない生徒は「名簿」タブの学年を表示

## ウィジェット

ホーム画面を長押し → ウィジェット →「今日のシフト」。今日の全員のシフトを表で表示します（1人1行「中2坪本(数)」の形）。
- ウィジェットの大きさに合わせて横一列／2段を切り替え、入りきらないときは文字を小さくします
- 今の時間帯を色付け。30分ごとにシフト表を読み込み直します（⟳ ですぐに読み込み）
- タップでアプリを開きます

## インストール

https://github.com/sekisho0218-star/schedule/releases/tag/latest-apk の `today-shift.apk` をダウンロードして、Files アプリから開きます。
初回は ⚙ でシフト表の URL を入力してください（シフト表は「リンクを知っている全員が閲覧可」が必要。ログインは不要）。

シフト表の読み取りは、バーチカル手帳と共通の部品（`android/shiftcore`）を使っています。
